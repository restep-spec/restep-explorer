Restep Explorer

Token and language

Kept only in this tab (sessionStorage), tied to the API’s origin, and only sent to that origin. It never goes in the link or in the curl, which uses $RESTEP_TOKEN.

Changes the API’s texts (errors, descriptions) if it offers them in that language (§5.6), and which translation of the language maps is shown. The data does not change.

Requests

The latest requests from this tab, with their curl equivalent and the response as it arrived.

Restep Explorer reads the discovery document (§4.2) and keeps nothing outside your browser. More in Tools. Restep is an open draft by wubytes.
